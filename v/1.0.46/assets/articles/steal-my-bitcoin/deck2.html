A researcher won a public "steal my bitcoin" bounty by breaking into a deliberately vulnerable server with php2shell, and published how. Here is what that does, and does not, mean.

One minute

  • Someone built a server on purpose to be vulnerable to php2shell, put ~$2,000 of bitcoin on it, and invited the internet to steal it.
  • On 25 October a skilled researcher did, in ~19 hours, and wrote it up.
  • That is real proof the flaw gives full control of a machine — the strongest public demonstration so far.
  • But it is a game with a consenting target, not a victim. Nobody was harmed.
  • So it does not change the standing answer: no named organisation breached through php2shell in the real world.

Was it the same bug?

  • Yes. It targeted PHP 8.4.26 — one version below the 8.4.27 that carries the fix.
  • It abused the same mechanism the PHP advisory names: the session upload-progress feature, the memory disclosure, and the memory-corruption flaws behind CVE-2026-109618 and CVE-2026-109619.
  • Not a new vulnerability. It is the known php2shell family, demonstrated end to end on an unpatched build.

A new attack vector? One wrinkle worth noting

  • Not a new vulnerability — but a new data point.
  • The usual advisories studied Apache mod_php and PHP-FPM. This challenge ran neither.
  • It ran PHP's built-in web server (php -S) with worker processes — a mode the project says is not for production.
  • The win shows that this built-in server, too, can be driven to full code execution. We have flagged it to add to the affected-systems table.

What a defender should take from it

  1. Patch to 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35, or your distribution's backport. 8.4.26 is vulnerable.
  2. As a stopgap, turn off upload-progress (session.upload_progress.enabled=0) — not a substitute for the update.
  3. Never run the built-in php -S server in production.
  4. Assume memory disclosure beats ASLR: a randomised layout is not a backstop here.
  5. Keep the proportion. One consenting honeypot fell to a specialist in 19 hours. Real-world named victims: still zero.
